## 概述

用户注册功能支持详细的错误提示，帮助用户理解注册失败的原因并采取正确的措施。

### 错误处理流程

```
用户输入 → 前端验证 → 后端验证 → 返回详细错误 → 前端展示
```

---

## 后端错误处理

### 错误响应格式

所有注册失败都使用统一的响应格式：

```json
{
  "code": 400,
  "message": "注册失败",
  "data": {
    "reason": "该用户名已注册，请更换用户名"
  }
}
```

### 错误代码

| 错误代码 | 说明 |
|---------|------|
| `400` | 业务错误（用户名重复、邮箱重复等） |
| `422` | 参数验证错误（格式不正确、长度不符合要求等） |
| `500` | 系统错误（数据库错误等） |

## 前端错误展示

### 错误展示方式

1. **Toast 提示** (短消息)
   - 用于一般错误提示
   - 显示2-3秒
   - 示例: `该用户名已注册，请更换用户名`

2. **详细错误** (长消息)
   - 用于需要详细说明的错误
   - 显示3秒
   - 示例: `密码至少6位，请重新输入`

### 错误处理逻辑

```javascript
try {
  const res = await this.$store.dispatch('user/register', {
    username: this.formData.username,
    email: this.formData.email,
    password: this.formData.password
  })
  // 注册成功
  uni.showToast({
    title: '注册成功',
    icon: 'success'
  })
} catch (error) {
  // 解析详细错误信息
  let errorMessage = error.data?.reason || error.message || '注册失败'
  
  // 显示错误提示
  uni.showToast({
    title: errorMessage,
    icon: 'none',
    duration: 3000
  })
}
```

## 失败情况说明

### 1. 用户名相关错误

#### 1.1 用户名已注册

**错误提示**: `该用户名已注册，请更换用户名`

**原因**: 该用户名已被其他用户使用

**解决方法**:
- 更换用户名
- 尝试添加数字或特殊字符

**后端返回**:
```json
{
  "code": 400,
  "message": "注册失败",
  "data": {
    "reason": "该用户名已注册，请更换用户名"
  }
}
```

---

#### 1.2 用户名过短

**错误提示**: `账号至少3个字符`

**原因**: 用户名长度少于3个字符

**解决方法**:
- 增加用户名长度
- 至少使用3个字符

**前端验证**: 客户端立即验证，不发送请求

---

#### 1.3 用户名过长

**错误提示**: `账号最多50个字符`

**原因**: 用户名长度超过50个字符

**解决方法**:
- 缩短用户名
- 不超过50个字符

**前端验证**: 客户端立即验证，不发送请求

---

#### 1.4 用户名为空

**错误提示**: `请输入账号`

**原因**: 未输入用户名

**解决方法**:
- 输入用户名
- 用户名不能为空

**前端验证**: 客户端立即验证，不发送请求

### 3. 邮箱相关错误

#### 3.1 邮箱已注册

**错误提示**: `该邮箱已注册，请更换邮箱`

**原因**: 该邮箱已被其他用户使用

**解决方法**:

**后端返回**:
```json
{
  "code": 400,

```

---

#### 3.2 邮箱格式错误

**错误提示**: `邮箱格式不正确`

**原因**: 邮箱格式不符合标准

**解决方法**:
- 检查邮箱格式
- 确保包含 @ 符号和域名
- 示例: `user@example.com`

**前端验证**: 客户端立即验证，不发送请求

**验证规则**:
```javascript
function validateEmail(email) {
  const re = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  return re.test(email)
}
```

---

#### 3.3 邮箱为空 (可选)

**说明**: 邮箱是可选字段，可以不填写

**不提供邮箱**:

```json
}
```

**提供邮箱**:
```json
{
  "username": "testuser",
  "email": "user@example.com",
  "password": "password123"
}
```

## API 文档

### POST /api/auth/register

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名，3-50字符 |
| password | string | 是 | 密码，6-50字符 |
| email | string | 否 | 邮箱地址 |

#### 成功响应 (200)

```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "user_id": 1,
    "username": "testuser",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

}
```

## 前端实现

### 注册页面

文件: `frontend/pages/register/register.vue`

#### 关键代码

```javascript
async handleRegister() {
  // 前端验证
  if (this.formData.username.length < 3) {
    uni.showToast({
      title: '账号至少3个字符',
      icon: 'none'
    })
    return
  }
  
  if (this.formData.email && !this.validateEmail(this.formData.email)) {
    uni.showToast({
      title: '邮箱格式不正确',
      icon: 'none'
    })
    return
  }
  
  if (this.formData.password.length < 6) {
    uni.showToast({
      title: '密码至少6位',
      icon: 'none'
    })
    return
  }
  
  // 发起注册请求
  try {
    await this.$store.dispatch('user/register', {
      username: this.formData.username,
      email: this.formData.email || undefined,
      password: this.formData.password
    })
    
    uni.showToast({
      title: '注册成功',
      icon: 'success'
    })
  } catch (error) {
    // 解析详细错误信息
    let errorMessage = error.data?.reason || error.message || '注册失败'
    
    uni.showToast({
      title: errorMessage,
      icon: 'none',
      duration: 3000
    })
  }
}
```

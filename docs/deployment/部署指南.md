## 环境要求

### 硬件要求
- **CPU**: 2核或以上
- **内存**: 4GB或以上
- **磁盘**: 20GB或以上

### 软件要求
- **操作系统**: Linux / macOS / Windows 10+
- **Docker**: 20.10+
- **Docker Compose**: 2.0+

### 可选服务
- **AI模型**: OpenAI兼容接口（DeepSeek、通义千问等）
- **MySQL**: 如不使用Docker，需要单独安装MySQL 8.0+

## 快速部署

### 1. 克隆项目
```bash
git clone <repository-url>
cd LifeManager
```

### 2. 配置环境变量
```bash
# 复制环境变量模板
cp backend/.env.example backend/.env

# 编辑.env文件，配置必要参数
# - DATABASE_URL: 数据库连接字符串
# - JWT_SECRET_KEY: JWT密钥（生产环境必须修改）
# - LLM_MODEL_API_KEY: AI模型API Key（可选）
```

### 3. 使用Docker Compose部署

#### Linux/macOS
```bash
chmod +x backend/scripts/deploy.sh
./backend/scripts/deploy.sh
```

#### Windows PowerShell
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\backend\scripts\deploy.ps1
```

### 4. 验证部署
访问以下地址验证服务是否正常：

- **后端API**: http://localhost:8000
- **API文档**: http://localhost:8000/docs
- **健康检查**: http://localhost:8000/health

## 手动部署

### 1. 安装依赖

#### 后端
```bash
cd backend
pip install -r requirements.txt
```

#### 前端（如需单独部署）
```bash
cd frontend
npm install
npm run build
```

### 2. 配置数据库

#### 使用本地MySQL
```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE lifemanager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'lifemanager'@'localhost' IDENTIFIED BY 'lifemanager_password';
GRANT ALL PRIVILEGES ON lifemanager.* TO 'lifemanager'@'localhost';
FLUSH PRIVILEGES;
```

#### 初始化数据库
```bash
cd backend
python init_db.py
python seed_data.py
```

### 3. 启动服务

#### 后端服务
```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

#### 使用Gunicorn（生产环境）
```bash
cd backend
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

### 4. 配置反向代理（可选）

使用Nginx配置反向代理：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 配置说明

### 后端配置（.env）

| 配置项 | 说明 | 默认值 | 必填 |
|--------|------|--------|------|
| APP_NAME | 应用名称 | LifeManager | 否 |
| APP_VERSION | 应用版本 | 1.0.0 | 否 |
| DEBUG | 调试模式 | True | 否 |
| HOST | 监听地址 | 0.0.0.0 | 否 |
| PORT | 监听端口 | 8000 | 否 |
| JWT_SECRET_KEY | JWT密钥 | - | **是** |
| DATABASE_URL | 数据库连接 | sqlite:///./lifemanager.db | **是** |
| LLM_MODEL_NAME | AI模型名称 | qwen3_32b_awq | 否 |
| LLM_MODEL_BASE_URL | AI API地址 | - | 否 |
| LLM_MODEL_API_KEY | AI API密钥 | - | 否 |

### AI模型配置

#### 使用OpenAI官方API
```env
LLM_MODEL_NAME=gpt-4
LLM_MODEL_BASE_URL=https://api.openai.com/v1

```

#### 使用DeepSeek

## 常见问题

### Q1: Docker启动失败
**问题**: Docker容器无法启动
**解决**:
```bash
# 查看容器日志
docker-compose logs backend

# 检查端口占用
netstat -ano | findstr :8000  # Windows
lsof -i :8000  # Linux/macOS

# 重启Docker服务
sudo systemctl restart docker  # Linux
```

### Q2: 数据库连接失败
**问题**: 无法连接到MySQL数据库
**解决**:
```bash
# 检查MySQL容器状态
docker-compose ps mysql

# 进入MySQL容器
docker-compose exec mysql mysql -u lifemanager -p

# 检查数据库权限
SHOW GRANTS FOR 'lifemanager'@'%';
```

### Q3: AI规划生成失败
**问题**: AI规划生成报错
**解决**:
1. 检查API Key是否正确
2. 检查网络连接是否正常
3. 检查API地址是否可访问
4. 查看后端日志：`docker-compose logs -f backend`

### Q4: 跨域问题
**问题**: 前端无法访问后端API
**解决**:
- 开发环境：已在后端配置CORS允许所有来源
- 生产环境：修改`CORS_ORIGINS`配置为具体域名

## 故障排查

### 查看日志
```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
docker-compose logs -f mysql

# 查看最近100行日志
docker-compose logs --tail=100 backend
```

### 进入容器调试
```bash
# 进入后端容器
docker-compose exec backend bash

# 进入MySQL容器
docker-compose exec mysql mysql -u lifemanager -p

# 查看数据库
USE lifemanager;
SHOW TABLES;
SELECT * FROM users LIMIT 10;
```

### 重新初始化数据库
```bash
# 停止服务
docker-compose down

# 删除数据卷（谨慎操作！）
docker volume rm lifemanager_mysql_data

# 重新启动
docker-compose up -d
```

### 备份和恢复

#### 备份数据库
```bash
# 导出数据库
docker-compose exec mysql mysqldump -u lifemanager -p lifemanager > backup.sql

# 备份到文件
docker-compose exec -T mysql mysqldump -u lifemanager -plifemanager_password lifemanager > backup_$(date +%Y%m%d).sql
```

#### 恢复数据库
```bash
# 导入数据库
docker-compose exec -T mysql mysql -u lifemanager -plifemanager_password lifemanager < backup.sql
```

## 安全建议

1. **修改默认密钥**: 生产环境必须修改`JWT_SECRET_KEY`
2. **使用HTTPS**: 生产环境配置SSL证书
3. **限制数据库访问**: 数据库不要暴露在公网
4. **定期备份**: 设置自动备份策略
5. **更新依赖**: 定期更新Docker镜像和Python依赖
6. **监控日志**: 配置日志监控和告警

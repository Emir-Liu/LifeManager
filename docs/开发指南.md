## 开发命令

### 启动后端服务
```bash
# 开发模式（支持热重载）
cd backend
python main.py

# 或使用 uvicorn
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 启动前端服务
```bash
# 使用 HBuilderX
打开 frontend 目录
运行 → 运行到浏览器/模拟器/手机

# 或使用 CLI（如果已安装）
cd frontend
npm run dev:mp-weixin  # 微信小程序
npm run dev:h5  # H5
```

### 访问服务
- 后端API: http://localhost:8000
- API文档: http://localhost:8000/docs
- 健康检查: http://localhost:8000/health

## 测试命令

### 运行所有测试
```bash
# 项目根目录
cd e:\project\LifeManager

# 运行所有测试
pytest tests/ -v

# 运行后端测试
cd backend
pytest tests/ -v

# 运行特定测试文件
pytest tests/test_auth.py -v
pytest tests/test_goals.py -v
```

### 运行特定测试类
```bash
# 测试任务服务
pytest tests/test_services.py::TestTaskService -v

# 测试目标服务
pytest tests/test_services.py::TestGoalService -v

# 测试规划服务
pytest tests/test_services.py::TestPlanService -v
```

### 运行特定测试用例
```bash
pytest tests/test_services.py::TestTaskService::test_create_task_success -v

# 显示详细错误信息
pytest tests/test_services.py::TestTaskService::test_create_task_success -v --tb=short
```

### 测试覆盖率
```bash
# 生成覆盖率报告
pytest tests/ --cov=app --cov-report=html

# 查看覆盖率（浏览器）
# 打开 htmlcov/index.html
```

### 运行集成测试
```bash
# 所有集成测试
pytest tests/integration/ -v

# E2E测试
pytest tests/integration/test_e2e_complete_flow.py -v

# API流程测试
pytest tests/integration/test_api_flow.py -v
```

### 跳过某些测试
```bash
# 跳过E2E测试
pytest tests/ -v --ignore=tests/e2e/

# 跳过前端测试
pytest tests/ -v --ignore=tests/frontend/
```

### 并行运行测试（提高速度）
```bash
# 安装 pytest-xdist
pip install pytest-xdist

# 使用多进程运行
pytest tests/ -v -n auto
```

## 部署命令

### Docker部署（推荐）
```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 重启服务
docker-compose restart

# 查看服务状态
docker-compose ps
```

### 使用部署脚本
```bash
# Windows PowerShell
.\backend\scripts\deploy.ps1

# Linux/macOS
chmod +x backend/scripts/deploy.sh
./backend/scripts/deploy.sh
```

### 手动部署
```bash
# 1. 初始化数据库
cd backend
python init_db.py

# 2. 填充测试数据
python seed_data.py

# 3. 使用Gunicorn启动（生产环境）
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

### 数据库迁移
```bash
# 生成迁移文件
alembic revision --autogenerate -m "描述"

# 执行迁移
alembic upgrade head

# 回滚
alembic downgrade -1
```

## 常用操作

### 查看日志
```bash
# 后端日志
tail -f backend/logs/app.log  # Linux/macOS
Get-Content backend\logs\app.log -Wait  # Windows PowerShell

# Docker日志
docker-compose logs -f backend
docker-compose logs -f mysql
```

### 进入数据库
```bash
# SQLite
cd backend
python -c "from app.core.database import engine; from sqlalchemy import text; conn = engine.connect(); print(conn.execute(text('SELECT * FROM users LIMIT 10')).fetchall())"

# MySQL（Docker）
docker-compose exec mysql mysql -u lifemanager -plifemanager_password lifemanager

# 执行SQL文件
docker-compose exec -T mysql mysql -u lifemanager -plifemanager_password lifemanager < backup.sql
```

### 备份数据库
```bash
# SQLite
cp backend/lifemanager.db backup_$(date +%Y%m%d).db

# MySQL
docker-compose exec mysql mysqldump -u lifemanager -plifemanager_password lifemanager > backup.sql
```

### 清理测试数据
```bash
# 删除测试数据库
rm backend/test.db
rm backend/test_integration.db
rm backend/test_*.db

# 清理Docker数据
docker-compose down -v  # 警告：会删除所有数据卷！
```

## 开发流程

### 新功能开发流程
1. 创建功能分支
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. 开发代码
   ```bash
   # 启动开发服务
   cd backend && python main.py
   # 在另一个终端启动前端
   cd frontend && npm run dev:h5
   ```

3. 编写测试
   ```bash
   # 创建测试文件
   touch backend/tests/test_your_feature.py

   # 运行测试
   pytest backend/tests/test_your_feature.py -v
   ```

4. 提交代码
   ```bash
   git add .
   git commit -m "feat: add your feature description"
   git push origin feature/your-feature-name
   ```

### Bug修复流程
1. 创建修复分支
   ```bash
   git checkout -b fix/bug-description
   ```

2. 定位问题
   ```bash
   # 运行测试定位错误
   pytest tests/ -v -k "test_case_name"
   ```

3. 修复并验证
   ```bash
   # 修复代码后运行测试
   pytest tests/ -v
   ```

4. 提交修复
   ```bash
   git add .
   git commit -m "fix: fix bug description"
   git push origin fix/bug-description
   ```

## 常见问题

### Q1: 测试运行失败
```bash
# 解决方案1: 清理测试数据库
rm backend/test*.db

# 解决方案2: 重新安装依赖
pip install -r requirements-dev.txt --force-reinstall

# 解决方案3: 检查Python版本
python --version  # 需要 Python 3.10+
```

### Q2: Docker启动失败
```bash
# 查看详细日志
docker-compose logs backend

# 检查端口占用
netstat -ano | findstr :8000  # Windows
lsof -i :8000  # Linux/macOS

# 重新构建镜像
docker-compose build --no-cache
```

### Q3: 数据库连接失败
```bash
# 检查数据库容器状态
docker-compose ps mysql

# 进入数据库容器
docker-compose exec mysql bash

# 检查数据库是否创建
docker-compose exec mysql mysql -u lifemanager -plifemanager_password -e "SHOW DATABASES;"
```

## 安全建议

1. **生产环境配置**
   - 修改 `JWT_SECRET_KEY` 为强密码
   - 使用HTTPS
   - 限制CORS来源
   - 启用CSRF防护

2. **敏感信息保护**
   - 不要提交 `.env` 文件到Git
   - 使用环境变量管理密钥
   - 定期更新依赖

3. **日志管理**
   - 生产环境关闭DEBUG模式
   - 配置日志轮转
   - 监控异常日志

## 页面导航

### 底部导航栏
所有页面包含统一的底部导航栏，支持以下页面跳转：

- 🎯 **目标** → `goals-view.html`
- 📋 **任务** → `tasks-view.html`
- 🤖 **AI助手** → `ai-assistant-enhanced.html` (中间位置，突出显示)
- 📅 **日程** → `timeline-view.html`
- 📊 **统计** → `statistics-enhanced.html`

### 页面间跳转

1. **首页** → 点击任务卡片 → **任务详情** (`task-detail.html`)
2. **任务详情** → 点击返回 → **任务列表** (`tasks-view.html`)
3. **任务详情** → 点击底部导航 → 其他页面
4. **AI助手** → 快捷操作"创建目标" → 跳转到目标创建
5. **AI助手** → 快捷操作"添加任务" → 跳转到任务列表

## 设计规范

### 色彩方案
- 主色调：`#667eea` 到 `#764ba2` 渐变
- 成功色：`#38ef7d`
- 警告色：`#ff6b6b`
- 中性色：`#e0e0e0`, `#999`, `#666`, `#333`

### 字体规范
- 字体族：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`
- 标题：16-18px，粗体
- 正文：14px，常规
- 辅助文字：12px，常规

### 间距规范
- 页面边距：15-20px
- 卡片内边距：15px
- 元素间距：10-15px
- 标题间距：15-20px

### 圆角规范
- 大卡片：16px
- 小卡片：12px
- 按钮：20px（圆角按钮）或 8-10px（方角按钮）

### 阴影规范
- 卡片阴影：`0 2px 8px rgba(0,0,0,0.08)`
- 弹窗阴影：`0 4px 16px rgba(0,0,0,0.12)`

## 使用说明

### 本地预览

1. 直接在浏览器中打开 HTML 文件：
   ```bash
   # Windows
   start timeline-view.html
   
   # macOS
   open timeline-view.html
   
   # Linux
   xdg-open timeline-view.html
   ```

2. 或使用本地服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```

### 跨域问题

由于浏览器安全限制，直接打开 HTML 文件时，页面跳转可能受限。建议使用本地服务器方式。

## 2. 设计概述

### 2.1 核心概念

**对话层**是用户与 AI 交互的前置层，用户通过自然语言对话来表达需求，AI 理解意图后生成操作，用户确认后执行。

**核心理念**：先对话理解，后执行操作。避免直接填写复杂表单，降低使用门槛。

### 2.2 设计目标

1. **自然交互**：用户可以用自然语言表达需求，无需学习复杂表单
2. **智能理解**：AI 能够准确理解用户意图，识别关键信息
3. **渐进式引导**：当信息不完整时，AI 主动提问引导用户补充
4. **可视化确认**：操作以可视化方式展示，用户清晰了解即将执行的操作
5. **可追溯性**：完整记录对话历史和操作记录，方便回顾和审计

### 2.3 用户价值

| 痛点 | 解决方案 |
|------|---------|
| 表单填写复杂 | 自然语言对话，AI 自动提取信息 |
| 不知道如何规划 | AI 提供建议，用户选择或修改 |
| 操作不可追溯 | 完整记录对话和操作历史 |
| 需要反复修改 | 对话中可以随时调整计划 |

## 3. 对话流程设计

### 3.1 目标规划对话

**使用场景**：用户想要创建一个新目标，需要 AI 帮助规划。

**对话流程**：

```
用户：我想在3个月内学会Python
AI：很好的目标！为了更好地帮助你规划，我需要了解一些信息：
    1. 你的Python基础如何？（完全零基础 / 有一些基础）
    2. 每周能投入多少时间学习？（如：每天2小时）
    3. 有具体的学习目标吗？（如：能够独立开发项目 / 考取证书）
用户：完全零基础，每天2小时，希望能独立开发项目
AI：明白了。基于你的情况，我为你规划了一个3个月的学习计划：
    📋 目标：学习Python编程
    ⏰ 时间：3个月（2026-03-01 至 2026-06-01）
    📊 总工时：约180小时

    📝 建议的学习阶段：
    第1个月：Python基础语法（60小时）
    第2个月：进阶知识和实践（60小时）
    第3个月：项目实战（60小时）

    是否确认创建这个目标？
用户：确认
AI：✅ 目标已创建！我为你生成了初步的任务列表，
    你可以查看并调整每个任务的具体时间安排。
```

**关键特性**：
- 渐进式信息收集
- 可视化规划展示
- 用户确认机制
- 自动生成任务

---

### 3.2 日程规划对话

**使用场景**：用户想要安排特定日期的任务和日程。

**对话流程**：

```
用户：下周一我想安排一天的学习
AI：好的，下周一（3月10日）。你想要：
    1. 安排哪些任务？
    2. 有什么时间限制或偏好吗？
用户：主要安排Python学习任务，上午9点到下午6点之间，
    中午要休息1小时
AI：查看你的任务列表，以下任务可以安排：
    📚 学习Python基础语法（3小时）
    📚 练习Python编程（2小时）

    📅 建议的时间安排：
    09:00 - 12:00 学习Python基础语法
    12:00 - 13:00 💤 午休
    14:00 - 16:00 练习Python编程

    是否确认这个安排？
用户：可以，把下午的练习改成下午3点到5点
AI：好的，已更新：
    09:00 - 12:00 学习Python基础语法
    12:00 - 13:00 💤 午休
    15:00 - 17:00 练习Python编程

    ✅ 时间安排已确认！
```

**关键特性**：
- 智能时间分配
- 考虑用户偏好
- 支持手动调整
- 冲突检测

### 3.3 任务调整对话

**使用场景**：用户想要调整已有任务。

**对话流程**：

```
用户：明天的任务时间冲突了，能帮我调整一下吗？
AI：好的，让我查看一下明天的安排...
    📅 2026-03-11（明天）
    09:00 - 11:00 学习Python（优先级：高）
    14:00 - 15:00 团队会议（固定日程，不可调整）
    15:00 - 17:00 准备周报（优先级：中）

    你想要调整哪个任务？
用户：把学习Python调整到下午
AI：下午可用时间段：
    15:00 - 18:00（3小时，足够完成学习任务）

    建议调整：
    09:00 - 11:00 ➜ 15:00 - 17:00 学习Python

    是否确认调整？
用户：确认
AI：✅ 任务时间已更新！
    新时间：15:00 - 17:00 学习Python
```

**关键特性**：
- 自动识别冲突
- 提供调整建议
- 考虑固定日程
- 智能时间推荐

### 3.4 通用聊天

**使用场景**：用户提出一般性问题或寻求建议。

**对话流程**：

```
用户：如何提高学习效率？
AI：以下是一些提高学习效率的建议：
    🎯 目标明确
    - 设定具体、可衡量的学习目标
    - 将大目标分解为小任务

    ⏰ 时间管理
    - 使用番茄工作法（25分钟专注 + 5分钟休息）
    - 避免长时间连续学习

    🔄 主动学习
    - 做笔记，总结知识点
    - 实践编程，不只是看书

    💪 保持健康
    - 保证充足睡眠
    - 适当运动，保持精力

    希望这些建议对你有帮助！
```

**关键特性**：
- 通用知识问答
- 学习建议
- 无操作执行

## 5. AI 对话设计

### 5.1 Prompt 设计原则

**1. 清晰明确**
- 明确 AI 的角色和职责
- 清晰说明任务要求
- 提供具体的输出格式

**2. 上下文感知**
- 包含对话历史
- 包含用户偏好
- 包含当前状态

**3. 渐进式引导**
- 信息不完整时主动提问
- 提供合理的默认值
- 避免一次性收集太多信息

**4. 友好交互**
- 使用自然、友好的语言
- 提供清晰的选项
- 给出有用的建议

## 6. 操作执行机制

### 6.1 操作识别

AI 分析用户回复，识别需要执行的操作：

**识别规则**：
1. **确认操作**：用户说"确认"、"好的"、"可以"等
2. **取消操作**：用户说"取消"、"不用了"等
3. **修改操作**：用户提供修改意见
4. **继续对话**：用户提出新问题

### 6.2 操作确认

**重要操作需要二次确认**：

```
AI：即将执行以下操作：
    📋 创建目标：学习Python
    ⏰ 时间：3个月
    📊 总工时：180小时

    [确认] [取消]
```

### 6.3 操作执行

**执行流程**：

```
1. 创建 ConversationAction 记录
   ↓
2. 调用对应的业务 API
   ↓
3. 更新操作状态
   ↓
4. 返回执行结果
```

**错误处理**：
- 执行失败：记录错误信息，提示用户
- 部分成功：标记部分成功，提示用户手动处理
- 完全成功：更新所有相关数据

### 6.4 执行反馈

**反馈格式**：

```
✅ 操作成功！

已创建目标：
📋 学习Python
⏰ 2026-03-01 至 2026-06-01
📊 总工时：180小时

已生成5个任务，你可以查看并调整。
```

```python
async def process_message(conversation_id: int, content: str):
    # 1. 保存用户消息
    message = await create_message(conversation_id, "user", content)

    # 2. 获取对话上下文
    context = await get_conversation_context(conversation_id)

    # 3. 生成 AI Prompt
    prompt = generate_prompt(content, context)

    # 4. 调用 AI 获取回复
    ai_response = await llm_operator.chat(prompt, stream=True)

    # 5. 处理 AI 回复
    for chunk in ai_response:
        # 流式发送
        await send_chunk(chunk)

        # 检测是否包含操作
        if contains_action(chunk):
            action = parse_action(chunk)
            await save_pending_action(action)
```

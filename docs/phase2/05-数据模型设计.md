## 3. 设计概述

### 3.1 设计目标

1. **支持交互式规划**：增加对话层，让用户通过对话与 AI 协同规划任务和日程
2. **周期性任务支持**：参考 Google Calendar 的 iCalendar 标准，实现灵活的周期性任务
3. **层级结构**：支持目标和任务的父子层级，便于任务分解
4. **数据完整性**：确保数据的完整性和一致性
5. **性能优化**：合理的索引设计和查询优化

### 3.2 设计原则

- **简单性**：保持模型简洁，避免过度设计
- **灵活性**：使用 JSON 字段存储复杂数据，便于扩展
- **标准化**：遵循业界标准（如 iCalendar RFC5545）
- **可维护性**：清晰的字段定义和关系映射

### 3.3 参考来源

| 来源 | 应用场景 |
|------|---------|
| Google Calendar API | 周期性规则（RRULE/EXDATE/RDATE） |
| Google Tasks API v1 | 任务层级结构、状态管理 |
| iCalendar RFC5545 | 周期性事件的标准格式 |
| SQLAlchemy 最佳实践 | ORM 模型设计和关系映射 |

## 5. 对话层模型

### 5.1 Conversation（对话会话）

```python
from sqlalchemy import Column, Integer, String, Text, DateTime, ForeignKey, JSON, Boolean, func
from sqlalchemy.orm import relationship
from app.core.database import Base


class Conversation(Base):
    """对话会话模型"""
    __tablename__ = "conversations"

    id = Column(Integer, primary_key=True, index=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False, index=True)

    # 基本信息
    title = Column(String(200), nullable=True, comment="对话标题")
    conversation_type = Column(
        String(20),
        nullable=False,
        default="goal_planning",
        comment="对话类型: goal_planning/schedule_planning/task_adjustment/general_chat"
    )

    # 状态管理
    status = Column(
        String(20),
        nullable=False,
        default="active",
        comment="状态: active/completed/cancelled"
    )

    # 关联信息
    related_goal_id = Column(Integer, ForeignKey("goals.id", ondelete="SET NULL"), nullable=True, comment="关联目标ID")
    related_plan_id = Column(Integer, ForeignKey("plans.id", ondelete="SET NULL"), nullable=True, comment="关联规划ID")

    # 上下文管理
    context_summary = Column(Text, nullable=True, comment="对话摘要")
    context_json = Column(JSON, nullable=True, comment="完整上下文数据")

    # 统计信息
    message_count = Column(Integer, default=0, comment="消息数量")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, onupdate=func.now())
    completed_at = Column(DateTime, nullable=True, comment="完成时间")

    # 关系
    user = relationship("User", back_populates="conversations")
    messages = relationship("ConversationMessage", back_populates="conversation", cascade="all, delete-orphan")
    actions = relationship("ConversationAction", back_populates="conversation", cascade="all, delete-orphan")

    def __repr__(self):
        return f"<Conversation(id={self.id}, title={self.title}, status={self.status})>"
```

**字段说明**：

- `conversation_type`：对话类型枚举
  - `goal_planning` - 目标规划对话
  - `schedule_planning` - 日程规划对话
  - `task_adjustment` - 任务调整对话
  - `general_chat` - 通用聊天

- `status`：会话状态枚举
  - `active` - 进行中
  - `completed` - 已完成
  - `cancelled` - 已取消

- `context_json`：存储完整对话上下文，格式示例：
  ```json
  {
    "user_intent": "create_goal",
    "goal_title": "学习Python",
    "goal_deadline": "2026-06-30",
    "preferences": {
      "daily_hours": 2,
      "priority": "high"
    },
    "constraints": {
      "available_hours": [18, 22],
      "exclude_days": ["Saturday", "Sunday"]
    }
  }
  ```

### 5.2 ConversationMessage（对话消息）

```python
class ConversationMessage(Base):

    id = Column(Integer, primary_key=True, index=True)

    # 消息序列

        String(20),
        nullable=False,
        default="text",
        comment="消息类型: text/image/code/action_request"
    )
    content = Column(Text, nullable=False, comment="消息内容")
    content_json = Column(JSON, nullable=True, comment="结构化内容数据")

    # AI 模型信息
    model_used = Column(String(50), nullable=True, comment="使用的AI模型")

    # 用户反馈
    user_feedback = Column(String(20), nullable=True, comment="用户反馈: like/dislike/neutral")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now())

    # 关系
    conversation = relationship("Conversation", back_populates="messages")
    actions = relationship("ConversationAction", back_populates="message", cascade="all, delete-orphan")

    def __repr__(self):
        return f"<ConversationMessage(id={self.id}, role={self.role}, sequence={self.sequence})>"
```

### 5.3 ConversationAction（对话操作）

```python
class ConversationAction(Base):
    """对话操作记录模型"""
    __tablename__ = "conversation_actions"

    id = Column(Integer, primary_key=True, index=True)
    message_id = Column(Integer, ForeignKey("conversation_messages.id", ondelete="CASCADE"), nullable=False, index=True)
    conversation_id = Column(Integer, ForeignKey("conversations.id", ondelete="CASCADE"), nullable=False, index=True)

    # 操作信息
    action_type = Column(
        String(30),
        nullable=False,
        comment="操作类型: create_goal/create_task/update_task/delete_task/create_event/update_event/delete_event"
    )
    status = Column(
        String(20),
        nullable=False,
        default="pending",
        comment="状态: pending/executed/failed/cancelled"
    )

    # 操作详情
    description = Column(String(500), nullable=True, comment="操作描述")
    action_data = Column(JSON, nullable=True, comment="操作数据")

    # 目标信息
    target_type = Column(String(50), nullable=True, comment="目标类型: goal/task/event")
    target_id = Column(Integer, nullable=True, comment="目标ID")

    # 执行结果
    result_message = Column(Text, nullable=True, comment="执行结果消息")
    executed_at = Column(DateTime, nullable=True, comment="执行时间")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now())

    # 关系
    message = relationship("ConversationMessage", back_populates="actions")
    conversation = relationship("Conversation", back_populates="actions")

    def __repr__(self):
        return f"<ConversationAction(id={self.id}, type={self.action_type}, status={self.status})>"
```

**字段说明**：

- `action_type`：操作类型
  - `create_goal` - 创建目标
  - `create_task` - 创建任务
  - `update_task` - 更新任务
  - `delete_task` - 删除任务
  - `create_event` - 创建日程
  - `update_event` - 更新日程
  - `delete_event` - 删除日程

- `action_data`：操作数据，格式示例：
  ```json
  {
    "goal": {
      "title": "学习Python",
      "description": "掌握Python编程基础",
      "deadline": "2026-06-30",
      "priority": "high"
    },
    "tasks": [
      {
        "title": "学习基础语法",
        "estimated_hours": 10,
        "due_date": "2026-03-15"
      }
    ]
  }
  ```

```python
    # 目标层级
    parent_id = Column(Integer, ForeignKey("goals.id", ondelete="CASCADE"), nullable=True, index=True, comment="父目标ID")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now(), comment="创建时间")
    updated_at = Column(DateTime, nullable=True, onupdate=func.now(), comment="更新时间")
    completed_at = Column(DateTime, nullable=True, comment="完成时间")

    # 关系
    user = relationship("User", back_populates="goals")
    parent = relationship("Goal", remote_side=[id], backref="children")
    plans = relationship("Plan", back_populates="goal", cascade="all, delete-orphan")
    tasks = relationship("Task", back_populates="goal", cascade="all, delete-orphan")

    def __repr__(self):
        return f"<Goal(id={self.id}, title={self.title}, status={self.status})>"
```

**新增字段说明**：

- `parent_id`：支持目标层级，便于目标分解和子目标管理
- `priority`：目标优先级，用于智能分配和排序
- `status`：新增 `planning_discussion` 状态，表示目标正在通过对话规划中

### 6.2 Task（任务）模型增强

```python
from sqlalchemy import Column, Integer, String, Text, Date, Time, DateTime, ForeignKey, Boolean, JSON, Enum, func
from sqlalchemy.orm import relationship
from app.core.database import Base


class TaskStatus(str, enum.Enum):
    """任务状态枚举"""
    NOT_STARTED = "not_started"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    CANCELLED = "cancelled"
    POSTPONED = "postponed"


class TaskType(str, enum.Enum):
    """任务类型枚举"""
    LEARNING = "learning"
    WORK = "work"
    LIFE = "life"
    HEALTH = "health"
    FIXED = "fixed"
    GENERAL = "general"


class Task(Base):
    """任务模型 - 增强版"""
    __tablename__ = "tasks"

    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    goal_id = Column(Integer, ForeignKey("goals.id", ondelete="CASCADE"), nullable=False, index=True, comment="目标ID")
    plan_id = Column(Integer, ForeignKey("plans.id", ondelete="CASCADE"), nullable=True, comment="规划ID")

    # 基本信息
    title = Column(String(200), nullable=False, comment="任务标题")
    description = Column(Text, nullable=True, comment="任务描述")
    due_date = Column(Date, nullable=False, index=True, comment="截止日期")

    # 状态管理
    completed = Column(Boolean, default=False, comment="是否完成")
    status = Column(Enum(TaskStatus), default=TaskStatus.NOT_STARTED, comment="任务状态")
    stage_name = Column(String(100), nullable=True, comment="阶段名称")

    # 时间管理
    estimated_hours = Column(Integer, default=0, comment="预估工时")
    start_time = Column(Time, nullable=True, comment="开始时间")
    end_time = Column(Time, nullable=True, comment="结束时间")
    duration_minutes = Column(Integer, nullable=True, comment="持续时间（分钟）")
    actual_start_time = Column(DateTime, nullable=True, comment="实际开始时间")
    actual_end_time = Column(DateTime, nullable=True, comment="实际结束时间")

    # 任务类型
    task_type = Column(Enum(TaskType), default=TaskType.GENERAL, comment="任务类型")

    # 任务层级
    parent_task_id = Column(Integer, ForeignKey("tasks.id", ondelete="CASCADE"), nullable=True, index=True, comment="父任务ID")

    # 任务顺序
    task_order = Column(Integer, default=0, comment="任务顺序")

    # 提醒设置
    reminder_enabled = Column(Boolean, default=True, comment="是否开启提醒")
    reminder_minutes_before = Column(Integer, default=30, comment="提前提醒分钟数")

    # 周期性任务规则（参考 Google Calendar iCalendar 标准）
    recurrence_rule = Column(JSON, nullable=True, comment="周期性规则")
    exdates = Column(JSON, nullable=True, comment="排除日期列表")
    rdates = Column(JSON, nullable=True, comment="额外日期列表")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now(), comment="创建时间")
    updated_at = Column(DateTime, nullable=True, onupdate=func.now(), comment="更新时间")

    # 关系
    goal = relationship("Goal", back_populates="tasks")
    plan = relationship("Plan", back_populates="tasks")
    parent_task = relationship("Task", remote_side=[id], backref="subtasks")

    def __repr__(self):
        return f"<Task(id={self.id}, title={self.title}, completed={self.completed})>"
```

**周期性任务规则格式**：

遵循 iCalendar RFC5545 标准，示例：

```json
{
  "rrule": "FREQ=WEEKLY;BYDAY=MO,WE,FR;INTERVAL=1;UNTIL=20261231T235959Z",
  "exdates": ["2026-03-10", "2026-03-17"],
  "rdates": ["2026-03-08"]
}
```

**RRULE 参数说明**：

| 参数 | 说明 | 示例 |
|------|------|------|
| FREQ | 频率 | DAILY/WEEKLY/MONTHLY/YEARLY |
| INTERVAL | 间隔 | 1=每周, 2=每两周 |
| BYDAY | 星期几 | MO,TU,WE,TH,FR,SA,SU |
| BYMONTHDAY | 每月第几天 | 1,15=每月1号和15号 |
| UNTIL | 结束日期 | 20261231T235959Z |

**示例 RRULE**：

```
FREQ=WEEKLY;BYDAY=MO,WE,FR;INTERVAL=1
# 每周一、三、五

FREQ=DAILY;UNTIL=20261231T235959Z
# 每天，直到2026年12月31日

FREQ=MONTHLY;BYMONTHDAY=15;INTERVAL=1
# 每月15号

FREQ=WEEKLY;BYDAY=MO;INTERVAL=2
# 每两周的周一
```

### 6.3 Event（日程）模型

```python
from sqlalchemy import Column, Integer, String, Text, Date, Time, DateTime, ForeignKey, Boolean, JSON, Enum, func
from sqlalchemy.orm import relationship
from app.core.database import Base


class EventType(str, enum.Enum):
    """日程类型枚举"""
    MEETING = "meeting"
    COURSE = "course"
    REMINDER = "reminder"
    GENERAL = "general"


class Event(Base):

    end_date = Column(Date, nullable=True, comment="结束日期（重复日程的结束日期）")

    # 颜色标记
    color = Column(String(7), nullable=False, default="#666666", comment="十六进制颜色")

    # 状态
    is_active = Column(Boolean, default=True, comment="是否激活")

    # 父日程（支持日程层级）
    parent_event_id = Column(Integer, ForeignKey("events.id", ondelete="SET NULL"), nullable=True, comment="父日程ID")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, onupdate=func.now())

    # 关系
    user = relationship("User", back_populates="events")
    parent_event = relationship("Event", remote_side=[id], backref="child_events")

    def __repr__(self):
        return f"<Event(id={self.id}, title={self.title}, start_date={self.start_date})>"
```

```python
class TimePreference(Base):
    """用户时间偏好模型"""
    __tablename__ = "time_preferences"

    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False, unique=True)

    # 作息类型
    sleep_type = Column(String(20), nullable=False, default='normal', comment="作息类型: early/normal/late")

    # 作息时间
    wake_up_time = Column(Time, nullable=False, default=time(7, 0), comment="起床时间")
    sleep_time = Column(Time, nullable=False, default=time(23, 0), comment="睡眠时间")
    lunch_start = Column(Time, nullable=False, default=time(12, 0), comment="午餐开始")
    lunch_end = Column(Time, nullable=False, default=time(13, 30), comment="午餐结束")

    # 工作时间段
    work_start = Column(Time, nullable=True, comment="工作开始时间")
    work_end = Column(Time, nullable=True, comment="工作结束时间")

    # 工作日（0-6，0=周一）
    work_days = Column(String(7), nullable=True, default="0,1,2,3,4", comment="工作日")

    # 学习时间段
    study_start = Column(Time, nullable=True, comment="学习开始时间")
    study_end = Column(Time, nullable=True, comment="学习结束时间")

    # 首选任务时间段
    preferred_task_start = Column(Time, nullable=True, comment="首选任务开始时间")
    preferred_task_end = Column(Time, nullable=True, comment="首选任务结束时间")

    # 缓冲时间（分钟）
    buffer_time_minutes = Column(Integer, nullable=False, default=10, comment="缓冲时间")

    # 时间戳
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, onupdate=func.now())

    # 关系
    user = relationship("User", back_populates="time_preferences")

    def __repr__(self):
        return f"<TimePreference(user_id={self.user_id}, sleep_type={self.sleep_type})>"
```

- 查询 JSON 字段时使用 PostgreSQL 的 JSON 操作符

## 🚀 快速开始

### 对于新加入的成员

1. 阅读 **01-项目概述.md** 了解项目背景
2. 阅读 **02-产品需求文档.md** 了解功能需求
3. 根据**角色**阅读相关文档：
   - **后端开发**：04 + 05 + 07 + 09
   - **前端开发**：04 + 06 + 08 + 09
   - **测试开发**：02 + 11
   - **项目经理**：01 + 02 + 10

### 对于开发任务

1. 查阅 **10-开发计划.md** 了解当前任务
2. 参考相关设计文档进行开发
3. 遵循 **09-开发规范** 的编码标准
4. 按照 **11-测试计划.md** 进行测试

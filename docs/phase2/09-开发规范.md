## 1. 代码规范

### 1.1 Python 代码规范

#### 1.1.1 基础规范

遵循 **PEP 8** 规范：

```python
# ✅ 正确示例
from datetime import datetime
from typing import List, Optional

class UserService:
    """用户服务类"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def get_user(self, user_id: int) -> Optional[User]:
        """获取用户信息

        Args:
            user_id: 用户ID

        Returns:
            用户对象或None
        """
        return await self.db.get(User, user_id)


# ❌ 错误示例
from datetime import datetime, time, date
class userservice:  # 类名应该使用 PascalCase
    def __init__(self, db):  # 参数缺少类型注解
        self.db = db

    def getuser(self, user_id):  # 方法名应该使用 snake_case
        return self.db.get(User, user_id)
```

#### 1.1.2 命名规范

| 类型 | 命名规范 | 示例 |
|------|---------|------|
| 类名 | PascalCase | `UserService`, `ConversationService` |
| 函数名 | snake_case | `get_user()`, `create_conversation()` |
| 变量名 | snake_case | `user_id`, `conversation_title` |
| 常量 | UPPER_CASE | `MAX_RETRY_COUNT`, `DEFAULT_PAGE_SIZE` |
| 私有方法 | 前缀下划线 | `_internal_method()` |
| 私有变量 | 前缀下划线 | `_internal_var` |

#### 1.1.3 类型注解

所有函数必须添加类型注解：

```python
from typing import List, Optional, Dict
from pydantic import BaseModel

async def get_tasks(
    user_id: int,
    status: Optional[str] = None,
    page: int = 1,
    page_size: int = 20
) -> Dict[str, any]:
    """获取任务列表"""
    pass


class TaskCreate(BaseModel):
    """任务创建模型"""
    title: str
    goal_id: int
    due_date: date
    estimated_hours: Optional[int] = None
```

#### 1.1.4 文档字符串

所有公共类和方法必须有文档字符串：

```python
class TaskService:
    """任务服务类

    负责任务的创建、更新、删除和查询操作。
    """

    async def create_task(
        self,
        task_data: TaskCreate,
        user_id: int
    ) -> Task:
        """创建任务

        Args:
            task_data: 任务数据
            user_id: 用户ID

        Returns:
            创建的任务对象

        Raises:
            ValueError: 目标不存在
            ValidationError: 数据验证失败

        Examples:
            >>> task_data = TaskCreate(title="学习Python", goal_id=1)
            >>> task = await task_service.create_task(task_data, user_id=1)
        """
        pass
```

#### 1.2.2 命名规范

| 类型 | 命名规范 | 示例 |
|------|---------|------|

| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |

#### 1.2.3 Vue 组件规范

```vue
<template>
  <div class="timeline">
    <!-- 模板内容 -->
  </div>
</template>

<script>
export default {
  name: 'TimelineView',

  components: {
    TaskCard,
    TimeMarker
  },

  props: {
    tasks: {
      type: Array,
      required: true,
      validator: (value) => {
        return Array.isArray(value)
      }
    },
    currentDate: {
      type: Date,
      default: () => new Date()
    }
  },

  data() {
    return {
      viewMode: 'day',
      isDragging: false
    }
  },

  computed: {
    sortedTasks() {
      return [...this.tasks].sort((a, b) => {
        return new Date(a.startTime) - new Date(b.startTime)
      })
    }
  },

  methods: {
    handleDragStart(task) {
      this.isDragging = true
      this.$emit('drag-start', task)
    }
  }
}
</script>

<style scoped>

  height: 100%;
  overflow-y: auto;
}
```

## 2. Git 规范

### 2.1 分支策略

采用 **Git Flow** 分支策略：

```
main (生产分支)
  ↑
develop (开发分支)
  ↑
feature/* (功能分支)
hotfix/* (修复分支)
```

#### 分支命名

| 分支类型 | 命名规范 | 示例 |
|---------|---------|------|
| 功能分支 | `feature/功能描述` | `feature/conversation-layer` |
| 修复分支 | `hotfix/问题描述` | `hotfix/fix-conflict-detection` |
| 发布分支 | `release/版本号` | `release/v2.0.0` |

### 2.2 提交信息规范

采用 **Conventional Commits** 规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

#### 类型 (type)

| 类型 | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | Bug 修复 |
| `docs` | 文档更新 |
| `style` | 代码格式（不影响功能） |
| `refactor` | 重构（不添加新功能也不修复 Bug） |
| `perf` | 性能优化 |
| `test` | 测试相关 |
| `chore` | 构建/工具相关 |

#### 提交示例

```bash
# ✅ 正确示例
feat(conversation): implement conversation message management

- Add ConversationMessage model
- Implement message service
- Add message API endpoints
- Support streaming response

Closes #123

# ❌ 错误示例
add message feature
fix bug
update
```

## 6. 最佳实践

### 6.1 后端开发

```python
# ✅ 使用依赖注入
from fastapi import Depends

async def get_task(
    task_id: int,
    task_service: TaskService = Depends()
) -> Task:
    return await task_service.get_task(task_id)


# ✅ 使用 Pydantic 验证
from pydantic import BaseModel, validator

class TaskCreate(BaseModel):
    title: str
    estimated_hours: int

    @validator('estimated_hours')
    def validate_hours(cls, v):
        if v < 0 or v > 24:
            raise ValueError('预估工时必须在 0-24 之间')
        return v
```

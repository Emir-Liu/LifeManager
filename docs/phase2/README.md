# LifeManager Phase 2：具体时间段任务安排功能

---

## 📌 阶段概述

Phase 2 在 Phase 1 MVP 的基础上，实现**具体时间段任务安排功能**，将 LifeManager 从"任务清单"升级为"智能日程助手"。

**核心创新**：
1. **对话层交互**：用户通过自然语言对话与 AI 协同规划任务和日程
2. **分钟级时间管理**：从"天级"升级到"分钟级"任务安排
3. **智能时间分配**：AI 自动为任务分配最佳时间段
4. **周期性任务支持**：参考 Google Calendar 的 iCalendar 标准

**时间**：6 周

### 三层架构

```
┌─────────────────────────────────────────────────────────┐
│  Conversation Layer (对话层)                            │
│  - Conversation (对话会话)                               │
│  - ConversationMessage (对话消息)                        │

└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│  Business Layer (业务层)                                │
│  - Goal (目标) - 增强版                                  │
│  - Task (任务) - 增强周期性支持                          │
│  - Event (日程) - 支持重复规则                           │
└─────────────────────────────────────────────────────────┘
                           ↓

│  Preference Layer (偏好层)                              │
│  - TimePreference (时间偏好)                            │
└─────────────────────────────────────────────────────────┘
```

## 🔑 关键特性

### 1. 对话层交互

用户可以通过自然语言对话来：
- 规划目标
- 安排日程
- 调整任务

AI 会理解用户意图，生成操作，用户确认后执行。

### 2. 智能时间分配

AI 根据以下因素自动分配任务时间：
- 用户时间偏好（作息、工作时段）
- 任务优先级和截止日期
- 固定日程
- 已安排任务

### 3. 周期性任务

参考 Google Calendar 的 iCalendar 标准：
- 支持 RRULE 规则
- 支持排除日期（EXDATE）
- 支持额外日期（RDATE）

### 4. 冲突检测

自动检测任务时间冲突，并提供解决建议。

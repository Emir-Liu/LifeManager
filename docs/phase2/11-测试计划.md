## 2. 测试类型

### 2.1 单元测试

**目标**：测试单个函数、方法、类的功能正确性

**覆盖范围**：
- 数据模型（Model）
- 业务服务（Service）
- 工具函数（Utils）

**覆盖率要求**：> 80%

**示例**：

```python
# tests/unit/test_conflict_service.py
import pytest
from datetime import time
from app.services.conflict_service import detect_conflict

def test_detect_conflict_no_conflict():
    """测试无冲突情况"""
    start_time = time(9, 0)
    end_time = time(11, 0)
    existing_tasks = []

    conflicts = detect_conflict(start_time, end_time, existing_tasks)

    assert len(conflicts) == 0


def test_detect_conflict_with_overlap():
    """测试有时间冲突"""
    start_time = time(9, 0)
    end_time = time(11, 0)

    class MockTask:
        start_time = time(10, 30)
        end_time = time(12, 0)

    existing_tasks = [MockTask()]

    conflicts = detect_conflict(start_time, end_time, existing_tasks)

    assert len(conflicts) == 1
    assert conflicts[0].overlap_minutes == 30
```

### 2.2 集成测试

**目标**：测试多个模块协作的正确性

**覆盖范围**：
- API 接口测试
- 数据库操作测试
- 外部服务集成测试

**示例**：

```python
# tests/integration/test_api_conversations.py
import pytest
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)

def test_create_conversation_success():
    """测试成功创建对话"""
    response = client.post(
        "/api/conversations",
        json={
            "title": "测试对话",
            "conversation_type": "goal_planning"
        },
        headers={"Authorization": "Bearer <token>"}
    )

    assert response.status_code == 200
    data = response.json()
    assert data["code"] == 0
    assert data["data"]["id"] > 0
    assert data["data"]["title"] == "测试对话"


def test_get_conversation_list():
    """测试获取对话列表"""
    response = client.get(
        "/api/conversations?status=active",
        headers={"Authorization": "Bearer <token>"}
    )

    assert response.status_code == 200
    data = response.json()
    assert "items" in data["data"]
```

### 2.3 端到端测试

**目标**：测试完整用户场景

**测试场景**：

#### 场景 1：目标规划对话

```
步骤：
1. 用户创建对话
2. 用户表达学习 Python 的需求
3. AI 询问详细信息
4. 用户补充信息
5. AI 生成规划
6. 用户确认
7. 系统创建目标和任务

验收：
- ✅ 对话流程完整
- ✅ AI 响应准确
- ✅ 目标创建成功
- ✅ 任务生成正确
```

#### 场景 2：智能时间分配

```
步骤：
1. 用户选择多个任务
2. 用户点击"智能分配"
3. 系统返回分配建议
4. 用户确认分配
5. 系统更新任务时间

验收：
- ✅ 分配结果合理
- ✅ 无时间冲突
- ✅ 任务时间更新成功
```

#### 场景 3：冲突检测和解决

```
步骤：
1. 用户创建任务（09:00-11:00）
2. 用户尝试创建另一个任务（10:30-12:00）
3. 系统检测到冲突
4. 显示冲突提示
5. 提供解决建议
6. 用户调整时间

验收：
- ✅ 冲突检测准确
- ✅ 冲突提示清晰
- ✅ 解决建议合理
```

### 2.4 性能测试

**目标**：确保系统性能达标

**测试指标**：

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| API 响应时间 | < 500ms | JMeter/locust |
| AI 响应时间（首字） | < 500ms | 手工测试 |
| 页面加载时间 | < 1s | Chrome DevTools |
| 数据库查询时间 | < 100ms | PostgreSQL EXPLAIN |

**示例**：

```python
# tests/performance/test_api_performance.py
import time
import pytest
from fastapi.testclient import TestClient

def test_conversation_api_response_time():
    """测试对话 API 响应时间"""
    client = TestClient(app)

    start = time.time()
    response = client.post(
        "/api/conversations",
        json={"title": "测试"},
        headers={"Authorization": "Bearer <token>"}
    )
    end = time.time()

    assert response.status_code == 200
    assert end - start < 0.5  # 响应时间 < 500ms
```

## 5. 测试流程

### 5.1 测试阶段

```
开发阶段
  ↓
单元测试 (开发人员)
  ↓
集成测试 (测试人员)
  ↓
系统测试 (测试人员)
  ↓
验收测试 (产品经理)
  ↓
上线
```

### 5.2 Bug 处理流程

```
发现 Bug
  ↓
提交 Bug 报告（Jira/GitHub Issues）
  ↓
开发人员修复
  ↓
测试人员验证
  ↓
Bug 修复完成
```

### 5.3 测试报告

每次测试完成后，提交测试报告，包含：

- 测试用例执行情况
- Bug 清单
- 覆盖率统计
- 性能指标
- 风险评估

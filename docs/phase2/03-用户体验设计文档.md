## 2. 用户画像

### 2.1 目标用户

| 用户类型 | 占比 | 特征 | 核心需求 |
|---------|------|------|---------|
| **职场人士** | 60% | 25-40岁，工作繁忙，注重效率 | 快速规划任务，智能时间分配 |
| **学生** | 30% | 18-25岁，学习压力大，有固定课程 | 课程管理，学习时间规划 |
| **自由职业者** | 10% | 年龄不限，自主安排时间 | 灵活的时间管理，项目追踪 |

### 2.2 用户痛点

1. **时间规划困难**：不知道如何合理安排时间
2. **任务冲突**：多个任务时间重叠
3. **提醒不及时**：错过重要任务和日程
4. **重复劳动**：每天都要手动创建重复任务
5. **缺乏反馈**：不知道时间花在哪里

## 3. 交互流程设计

### 3.1 对话规划流程

```
开始
  ↓
用户进入对话界面
  ↓
用户直接说出需求（如"我想在一个月内学会Python"）
  ↓
AI 识别意图并提问引导
  ↓
用户回答问题
  ↓
AI 生成初步计划和安排
  ↓
AI 请求人工确认
  ↓
用户确认/调整
  ↓
AI 更新计划并创建目标/任务/日程
  ↓
完成
```

**流程说明**：
1. **自然对话**：用户无需选择对话类型，直接用自然语言表达需求
2. **AI 智能识别**：AI 自动识别用户意图（目标规划/日程规划/任务调整）
3. **引导提问**：AI 根据需求智能提出相关问题
4. **生成方案**：AI 生成完整的计划和安排
5. **人工确认**：AI 提供操作建议，请求用户确认
6. **自动执行**：用户确认后，AI 自动创建目标、任务和日程

### 3.2 时间线视图交互

**核心交互**：
- **拖拽调整**：拖动任务卡片调整时间
- **点击编辑**：点击任务卡片打开编辑对话框
- **双击查看**：双击查看任务详情
- **长按删除**：长按显示删除选项

**手势支持**（移动端）：
- **双指缩放**：缩放时间轴
- **滑动切换**：左右滑动切换日期
- **下拉刷新**：刷新任务列表

### 3.3 智能分配流程

```
用户选择任务
  ↓
点击"智能分配"
  ↓
系统分析用户偏好
  ↓
显示推荐时间段
  ↓
用户选择时间段
  ↓
系统分配时间并保存
  ↓
完成
```

✅ 所有更新操作必须人工确认
✅ 提供多个解决方案供用户选择
✅ 支持批量操作和灵活调整
✅ 实时冲突检测和提示

## 5. 交互设计细节

### 5.1 对话操作确认

**操作建议卡片**：
```
┌─────────────────────────────────────┐
│  💡 AI 建议的操作                  │
│  ─────────────────────────────────│
│  📝 创建目标：Python 基础学习      │
│  📅 截止日期：2026-04-05          │
│  📊 任务数量：20个                 │
│  ⏱️ 预计时长：30天                │
│  📌 每日学习：2小时               │
│                                     │
│  [✅ 确认创建]  [✏️ 修改]  [❌ 取消]│
└─────────────────────────────────────┘
```

**操作类型样式**：
- **创建目标**：绿色主题，📝 图标
- **创建任务**：蓝色主题，✓ 图标
- **创建日程**：紫色主题，📅 图标
- **更新任务**：橙色主题，🔄 图标
- **删除任务**：红色主题，🗑️ 图标

**交互反馈**：
- **确认**：
  1. 显示加载动画
  2. 执行创建/更新操作
  3. 显示成功提示："✨ 目标创建成功！"
  4. 发送确认消息到对话

- **修改**：
  1. 展开编辑表单
  2. 用户调整参数
  3. 重新生成预览
  4. 再次请求确认

- **取消**：
  1. 隐藏操作卡片
  2. 发送消息："好的，已取消"
  3. 继续对话

### 5.2 时间冲突处理

**冲突检测触发时机**：
- 用户通过对话请求添加/修改任务时
- 用户拖拽调整任务时间时
- AI 自动分配任务时间时

**冲突提示对话框**：
```
┌─────────────────────────────────────┐
│  ⚠️ 检测到时间冲突                  │
│  ─────────────────────────────────│
│  冲突时间段：09:00 - 11:00         │
│                                     │
│  已有任务：                         │
│  📝 晨跑 (每周一、三、五)          │
│  📍 健身房                          │
│  ⏱️ 09:00 - 10:00                  │
│                                     │
│  新任务：                           │
│  📝 Python 学习                    │
│  📍 家                             │
│  ⏱️ 09:00 - 11:00                  │
│                                     │
│  💡 AI 建议：                       │
│  方案1：将 Python 学习调整到       │
│         14:00 - 16:00 (推荐)        │
│  方案2：将晨跑调整到 07:00 - 08:00  │
│  方案3：合并两个任务，边跑边听     │
│                                     │
│  [✅ 方案1] [⏭️ 方案2] [🔄 方案3]  │
│  [❌ 取消]  [✏️ 自定义时间]         │
└─────────────────────────────────────┘
```

**AI 智能建议规则**：
1. **优先推荐空时段**：分析用户时间偏好，推荐最佳空闲时段
2. **考虑学习曲线**：学习类任务优先安排在用户精力最好的时段
3. **分散任务**：避免连续安排高强度任务
4. **预留缓冲**：任务之间保留10-15分钟缓冲时间
5. **考虑习惯**：参考用户历史数据，推荐习惯时段

**人工确认流程**：
```
冲突检测
  ↓
AI 生成3个解决方案
  ↓
显示冲突对话框 + AI建议
  ↓
用户选择方案/自定义时间
  ↓
AI 生成操作建议卡片
  ↓
用户再次确认
  ↓
执行更新
```

**拖拽调整冲突处理**：
1. **拖拽时**：显示目标位置预览，实时检测冲突
2. **释放后**：
   - 无冲突：直接更新任务时间
   - 有冲突：显示冲突对话框，提供 AI 建议
3. **用户选择**：
   - 选择 AI 建议方案 → 更新时间
   - 自定义时间 → 手动调整 → 再次检测冲突
   - 取消 → 恢复原位置

## 6. 响应式设计

### 6.1 移动端适配

**断点**：
- **小屏手机**：< 375px
- **手机**：375px - 768px
- **平板**：768px - 1024px
- **桌面**：> 1024px

**适配策略**：
- **字体大小**：使用相对单位（rem, vw）
- **布局调整**：Flexbox/Grid 自适应布局
- **触摸优化**：增大点击区域（最小 44x44px）
- **手势支持**：滑动、缩放、长按

### 6.2 横竖屏适配

**竖屏**：
- 单列布局
- 时间线垂直滚动
- 日历显示一周

**横屏**：
- 双列布局
- 时间线水平滚动
- 日历显示一月

### 8.1 加载优化

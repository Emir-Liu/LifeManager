## 快速开始

### 1. 注册账号
1. 打开应用或访问网站
2. 点击"注册"按钮
3. 输入用户名、密码和邮箱
4. 点击"注册"完成

### 2. 创建第一个目标
1. 登录后，点击底部"目标"标签
2. 点击"+"按钮创建目标
3. 输入目标标题（如"学习Python"）
4. 添加目标描述（可选）
5. 设置截止日期（可选）
6. 点击"确认"

### 3. 生成智能规划
1. 在目标详情页，点击"生成规划"
2. 选择每日可用时间（如2小时）
3. 等待AI生成规划
4. 查看生成的阶段和任务
5. 点击"确认规划"创建任务

### 4. 开始完成任务
1. 点击底部"任务"标签
2. 查看今日任务列表
3. 点击任务开始执行
4. 完成后勾选任务

## 核心功能

### 🎯 目标管理
- **创建目标**: 定义您的长期目标
- **查看进度**: 实时跟踪目标完成度
- **编辑目标**: 更新目标描述和截止日期
- **删除目标**: 删除不再需要的目标

### 🤖 AI智能规划
- **自动分解**: AI自动将目标分解为多个阶段
- **任务生成**: 每个阶段包含具体任务
- **时间估算**: 智能估算每个任务所需时间
- **个性化调整**: 根据您的时间安排生成规划

### ✅ 任务管理
- **任务列表**: 按日期查看所有任务
- **任务详情**: 查看任务完整信息
- **完成任务**: 勾选标记任务完成
- **进度跟踪**: 实时查看完成进度

### 📊 统计分析
- **目标统计**: 查看总目标数、进行中、已完成
- **任务统计**: 查看任务完成情况
- **进度展示**: 可视化显示完成进度

## 使用指南

### 目标创建

#### 步骤1: 进入创建页面
点击底部"+"按钮或"目标"页面的创建按钮

#### 步骤2: 填写目标信息
- **标题**: 清晰的目标名称（如"在3个月内学习Python"）
- **描述**: 详细的目标描述（可选）
- **截止日期**: 目标完成日期（可选）

#### 步骤3: 保存目标
点击"确认"保存目标

**提示**:
- 目标标题要具体明确
- 目标描述可以详细说明要达到的效果
- 截止日期有助于规划时间安排

---

### AI规划生成

#### 准备工作
确保已安装AI服务，或配置了外部AI API

#### 生成步骤
1. 在目标详情页点击"生成规划"
2. 系统询问"每日可用时间"
3. 选择时间（1-8小时）
4. AI开始生成规划（通常10-30秒）

#### 查看规划
规划包含：
- **3-5个阶段**: 按时间顺序排列
- **每个阶段**: 包含3-8个具体任务
- **时间估算**: 每个任务的预估时间

#### 确认规划
- 查看完整规划内容
- 如不满意可以重新生成
- 满意后点击"确认规划"
- 系统自动创建所有任务并分配日期

**提示**:
- 每日时间越多，规划越详细
- 可以多次生成选择最好的方案
- 确认后任务将按日期分配

---

### 任务执行

#### 查看任务
- **今日任务**: 显示今天的所有任务
- **全部任务**: 显示所有待办任务
- 按日期分组: 任务按截止日期排列

#### 完成任务
1. 点击任务进入详情
2. 点击"完成任务"按钮
3. 任务标记为已完成
4. 目标进度自动更新

**快捷操作**:
- 任务列表中直接勾选完成任务
- 点击任务标题查看详情

---

### 目标管理

#### 查看目标
- 底部"目标"标签
- 查看所有目标列表
- 目标卡片显示进度和状态

#### 目标状态
- **规划中**: 目标已创建，未生成规划
- **进行中**: 已生成规划并确认，任务执行中
- **已完成**: 所有相关任务已完成

#### 编辑目标
1. 点击目标卡片
2. 进入目标详情页
3. 点击"编辑"按钮
4. 修改目标信息
5. 保存更改

#### 删除目标
1. 在目标列表中，点击目标卡片右上角的"×"
2. 确认删除操作
3. 目标及其所有任务将被删除

**警告**: 删除操作无法撤销，请谨慎操作！

## 常见问题

### Q1: AI规划生成失败怎么办？
**A**:
1. 检查网络连接是否正常
2. 检查AI API配置是否正确
3. 稍后重试（AI服务可能暂时不可用）
4. 联系技术支持

### Q2: 如何修改已生成的规划？
**A**:
- 已确认的规划无法直接修改
- 可以删除目标重新创建
- 或手动添加/删除任务

### Q3: 任务过期了怎么办？
**A**:
- 过期任务仍然可以完成
- 不影响目标进度
- 建议及时完成避免积累

### Q4: 可以同时创建多个目标吗？
**A**:
- 可以，没有限制
- 建议专注于1-3个主要目标
- 太多目标可能导致注意力分散

### Q5: 如何导出数据？
**A**:
- 当前版本暂不支持导出
- 未来版本将添加数据导出功能
- 可以截图保存进度

## 最佳实践

### 设定目标
1. **SMART原则**:
   - Specific（具体）
   - Measurable（可衡量）
   - Achievable（可实现）
   - Relevant（相关）
   - Time-bound（有时限）

2. **目标示例**:
   - ✅ "在3个月内掌握Python基础和进阶知识"
   - ❌ "学习编程"

### 规划执行
1. **每日坚持**: 按规划每天执行任务
2. **灵活调整**: 根据实际情况调整时间安排
3. **记录进度**: 定期查看进度，保持动力
4. **庆祝里程碑**: 完成阶段后庆祝小胜利

### 时间管理
1. **专注单一任务**: 一次只做一件事
2. **番茄工作法**: 25分钟专注+5分钟休息
3. **优先级排序**: 重要紧急任务优先
4. **预留缓冲**: 预留10-20%缓冲时间

### 使用技巧
1. **定期回顾**: 每周回顾目标进度
2. **调整规划**: 根据实际情况调整
3. **保持耐心**: 大目标需要时间积累
4. **寻求支持**: 分享目标，获得鼓励

## 💡 MVP 说明

**MVP (Minimum Viable Product)** 最小可行产品，只实现核心功能：

### ✅ MVP 包含的功能（第一阶段）
- 用户注册登录
- 目标创建和管理
- **AI 自动生成规划**（核心价值）
- 规划查看和确认
- 任务自动创建
- 任务执行和完成

### ❌ MVP 不包含的功能（第二阶段）
- 提醒通知
- 数据统计
- 日历视图
- 任务编辑
- 多平台支持

这些功能将在 MVP 验证成功后，根据用户反馈逐步添加。

## 🚀 快速开始

### 快速搭建 MVP 环境

```bash
# 1. 前端开发（使用 HBuilderX）
# 打开 e:/project/LifeManager/frontend
# 运行 → 运行到浏览器/手机

# 2. 后端开发
cd e:/project/LifeManager/backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py

# 访问 API 文档
# http://localhost:8000/docs
```

## 项目简介

LifeManager 是一款 AI 智能人生管理助手，帮助用户实现目标、规划日程、高效完成任务。

### 核心价值

**AI 智能规划** - 用户输入目标，AI 自动生成执行规划并安排日程

## 核心功能

### 必须实现的功能 (P0)

| 功能模块 | 说明 |
|---------|------|
| **用户系统** | 注册、登录 |
| **创建目标** | 输入目标和描述 |
| **AI 生成规划** | 调用 AI 生成执行步骤 ⭐ 核心 |
| **查看规划** | 浏览 AI 生成的规划 |
| **确认规划** | 用户确认后创建任务 |
| **任务列表** | 查看每日任务 |
| **完成任务** | 标记任务完成 |

### 暂不实现的功能 (第二阶段)

- ❌ 提醒通知
- ❌ 数据统计
- ❌ 日历视图
- ❌ 任务编辑
- ❌ 多平台支持

---

## 技术栈

### 前端
- **框架**: Vue 3 + Uni-app
- **开发工具**: HBuilderX
- **状态管理**: Vuex
- **UI 组件**: 自定义组件

### 后端
- **框架**: FastAPI
- **数据库**: MySQL
- **认证**: JWT
- **AI 集成**: 通用 OpenAI 接口 (支持 OpenAI 官方 API 和兼容服务)
- **数据验证**: Pydantic

---

## 核心流程

```
用户注册/登录
    ↓
创建目标
    ↓
AI 生成规划
    ↓
查看规划
    ↓
确认规划
    ↓
安排任务到日程
    ↓
执行任务
```

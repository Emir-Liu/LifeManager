## 1. 设计概述

### 1.1 设计目标

创建简洁、易用的 MVP 界面，让用户能够：
- 快速注册登录
- 轻松创建目标
- 清晰查看 AI 生成的规划
- 便捷完成每日任务

### 1.2 设计原则

- **简洁优先**: MVP 阶段只保留核心功能，避免复杂交互
- **渐进披露**: 重要信息突出显示，次要信息折叠
- **一致性**: 保持颜色、字体、间距的统一
- **反馈及时**: 操作有明确的视觉反馈

### 1.3 设计风格

- **主色调**: 紫色系（渐变）- 体现科技感和 AI 智能特性
- **辅助色**: 灰色系 - 用于次要信息和分隔
- **强调色**: 绿色 - 表示成功、完成状态
- **警告色**: 橙色 - 提示用户注意
- **错误色**: 红色 - 错误提示

## 3. 页面设计

### 3.1 首页 (Index)

#### 页面布局

```
┌─────────────────────────────┐
│        托管人生             │  Logo + 标题
│    AI 智能人生管理助手      │  副标题
│                             │
│   [渐变紫色背景]            │
│                             │
│      [主按钮] 开始使用       │  大按钮
│      [次按钮] 已有账号登录   │  小按钮
│                             │
└─────────────────────────────┘
```

#### 设计要点

- 背景使用紫色渐变 (`linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%)`)
- 标题大号白色字体，居中显示
- 主按钮：白色背景，紫色文字，圆角 12px，高度 48px
- 次按钮：透明背景，白色边框，圆角 8px，高度 40px
- 底部留白，按钮距底部约 1/3 屏幕高度

#### 交互说明

- 点击"开始使用" → 跳转到注册页
- 点击"已有账号登录" → 跳转到登录页

---

### 3.2 登录页 (Login)

#### 页面布局

```
┌─────────────────────────────┐
│     ←  用户登录             │  返回按钮 + 标题
│                             │
│   [输入框] 用户名           │  l-input 组件
│   [输入框] 密码             │  l-input 组件
│                             │
│    [登录按钮]               │  l-button 组件
│                             │
│    还没有账号？立即注册      │  链接文字
│                             │
└─────────────────────────────┘
```

#### 设计要点

- 顶部返回按钮（左箭头图标）
- 标题居中，大号字体
- 输入框使用 `l-input` 组件，带图标
- 登录按钮全宽，紫色渐变背景
- 底部链接文字，点击跳转注册

#### 交互说明

- 点击返回 → 返回首页
- 输入框获得焦点 → 下划线变紫色
- 点击登录 → 调用登录接口
  - 成功 → 保存 token，跳转到目标列表
  - 失败 → 显示错误提示

### 3.3 注册页 (Register)

#### 页面布局

```
┌─────────────────────────────┐
│     ←  注册账号             │  返回按钮 + 标题
│                             │
│   [输入框] 用户名           │  l-input 组件
│   [输入框] 密码             │  l-input 组件
│   [输入框] 确认密码         │  l-input 组件
│                             │
│    [注册按钮]               │  l-button 组件
│                             │
│    已有账号？立即登录        │  链接文字
│                             │
└─────────────────────────────┘
```

#### 设计要点

- 布局与登录页类似
- 三个输入框：用户名、密码、确认密码
- 密码输入框右侧显示眼睛图标（显示/隐藏密码）
- 注册按钮全宽，紫色渐变背景

#### 交互说明

- 点击返回 → 返回首页
- 输入框失去焦点时进行实时验证
  - 用户名：不能为空，3-20 字符
  - 密码：不能为空，6-20 字符
  - 确认密码：必须与密码一致
- 点击注册 → 调用注册接口
  - 成功 → 保存 token，跳转到目标列表
  - 失败 → 显示错误提示

#### 页面布局

```

│                             │

│  │ 学习 Python 编程      │  │  目标标题
│  │ 在3个月内掌握Python...  │  │  目标描述
│  │ 截止日期: 2025-04-26  │  │  截止日期
│  │ 状态: 规划中           │  │  状态
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │ ⭐ AI 智能规划       │  │  标题
│  │                       │  │
│  │ 第一阶段：基础学习     │  │  阶段名称
│  │ • 安装环境             │  │  任务列表
│  │ • 学习变量             │  │
│  │ • 学习函数             │  │
│  │                       │  │
│  │ 第二阶段：进阶提升     │  │
│  │ • 实战项目             │  │
│  │ • ...                  │  │
│  └───────────────────────┘  │
│                             │
│  [生成规划]                 │  规划中状态
│  [确认规划] [重新生成]     │  草稿状态
│  [查看任务]                 │  已确认状态
│                             │
└─────────────────────────────┘
```

#### 设计要点

- **规划中状态**：
  - 显示目标信息
  - 显示"暂无规划"提示
  - 显示"生成规划"按钮（紫色渐变）

- **草稿状态**（规划已生成，未确认）：
  - 显示目标信息
  - 显示 AI 生成的规划内容
  - 规划可编辑（点击阶段展开/折叠）
  - 显示"确认规划"和"重新生成"按钮

- **已确认状态**（规划已确认）：
  - 显示目标信息
  - 显示规划概览（只读）
  - 显示"查看任务"按钮

#### 交互说明

- 点击"生成规划"：
  - 弹出加载动画
  - 调用 AI 接口
  - 成功 → 切换到草稿状态
  - 失败 → 显示错误提示

- 点击"确认规划"：
  - 调用确认接口
  - 成功 → 自动创建任务，跳转到任务列表

- 点击"查看任务"：
  - 跳转到任务列表页

## 4. 组件设计

### 4.1 l-button 组件

#### 类型

1. **Primary (主按钮)**
   - 紫色渐变背景
   - 白色文字
   - 圆角 12px
   - 高度 48px
   - 用于主要操作（登录、注册、确认等）

2. **Secondary (次按钮)**
   - 白色背景
   - 紫色边框
   - 紫色文字
   - 圆角 8px
   - 高度 40px
   - 用于次要操作（取消、返回等）

3. **Text (文字按钮)**
   - 透明背景
   - 紫色文字
   - 用于链接式按钮

#### 状态

- **Normal**: 正常状态
- **Pressed**: 点击效果（透明度 0.8）
- **Disabled**: 禁用状态（灰色，不可点击）

---

### 4.2 l-input 组件

#### 结构

```
┌──────────────────────┐
│ [图标] 输入框内容    │
└──────────────────────┘
```

#### 样式

- 灰色边框（#e5e7eb）
- 圆角 8px
- 高度 48px
- 左侧图标（可选）
- 右侧图标（可选，如密码眼睛图标）

#### 状态

- **Normal**: 灰色边框
- **Focus**: 紫色边框 (#7c3aed)
- **Error**: 红色边框 + 错误提示
- **Disabled**: 灰色背景，不可编辑

---

## 5. 交互设计

### 5.1 动画效果

#### 页面转场
- 使用 Uni-app 内置转场效果
- push → 从右滑入
- pop → 向右滑出

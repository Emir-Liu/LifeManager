## 1. 核心价值

**AI 智能规划** - 用户输入目标，AI 自动生成执行规划并安排日程

## 4. 核心流程

### 用户使用流程

```
1. 用户注册/登录
    ↓
2. 创建目标
   - 输入：目标名称、描述、期望完成时间
    ↓
3. AI 生成规划
   - 调用 AI API
   - AI 分析目标，生成执行步骤
   - AI 估算每个步骤的时间
    ↓
4. 查看规划
   - 展示 AI 生成的规划
   - 显示每个阶段、每个任务
    ↓
5. 确认/修改规划
   - 用户可以修改规划
   - 用户确认后保存
    ↓
6. 安排任务到日程
   - 根据规划生成任务
   - 自动分配到日期
    ↓
7. 执行任务
   - 用户按日程完成任务
   - 标记完成状态
```

## 5. 核心表结构

```sql
-- 用户表
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 目标表
CREATE TABLE goals (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    deadline DATE,
    status VARCHAR(20) DEFAULT 'planning', -- planning, confirmed, completed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 规划表（AI 生成的规划）
CREATE TABLE plans (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    goal_id BIGINT NOT NULL,
    content TEXT NOT NULL, -- AI 生成的完整规划内容（JSON）
    status VARCHAR(20) DEFAULT 'draft', -- draft, confirmed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (goal_id) REFERENCES goals(id)
);

-- 任务表（从规划中生成）
CREATE TABLE tasks (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    goal_id BIGINT NOT NULL,
    plan_id BIGINT,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    due_date DATE NOT NULL,
    completed TINYINT(1) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (goal_id) REFERENCES goals(id),
    FOREIGN KEY (plan_id) REFERENCES plans(id)
);
```

## 7. AI 规划提示词设计

### Prompt 模板

```python
prompt = f"""
你是一个专业的目标规划助手。请根据用户的目标，生成一个详细的执行规划。

目标信息：
- 目标名称：{goal.title}
- 目标描述：{goal.description}
- 期望完成时间：{goal.deadline}
- 可用时间：每天约 {available_hours} 小时

要求：
1. 将目标分解为具体的阶段和任务
2. 估算每个任务的预估时间
3. 按照时间顺序安排任务
4. 考虑任务的依赖关系
5. 提供清晰的里程碑

请以 JSON 格式返回规划：
{{
  "stages": [
    {{
      "name": "阶段名称",
      "tasks": [
        {{
          "title": "任务标题",
          "description": "任务描述",
          "estimated_hours": 2,
          "order": 1
        }}
      ]
    }}
  ]
}}
"""
```

## 8. 数据模型

### 用户 (User)
```javascript
{
  id: BigInt,
  username: String,      // 3-20字符，字母/数字/下划线
  password_hash: String,  // bcrypt 加密
  created_at: Timestamp
}
```

### 目标 (Goal)
```javascript
{
  id: BigInt,
  user_id: BigInt,
  title: String,         // 1-200字符
  description: String,    // 可选，最多500字
  deadline: Date,         // YYYY-MM-DD
  status: String,         // planning | confirmed | completed
  created_at: Timestamp
}
```

### 规划 (Plan)
```javascript
{
  id: BigInt,
  goal_id: BigInt,
  content: JSON,          // AI 生成的完整规划
  status: String,         // draft | confirmed
  created_at: Timestamp
}
```

### 任务 (Task)
```javascript
{
  id: BigInt,
  goal_id: BigInt,
  plan_id: BigInt,       // 可选（手动创建的任务）
  title: String,          // 1-200字符
  description: String,    // 可选
  due_date: Date,         // YYYY-MM-DD
  completed: Boolean,
  created_at: Timestamp
}
```

## 10. 验证规则

### 注册验证
- 用户名：3-20字符，仅支持字母/数字/下划线，唯一性检查
- 密码：至少6位字符
- 确认密码：必须与密码一致
- 邮箱（选填）：有效的邮箱格式

### 目标验证
- 标题：1-200字符，必填
- 描述：最多500字，选填
- 截止日期：必须晚于当前日期

### 规划验证
- 必须至少包含一个阶段
- 每个阶段至少包含一个任务
- 任务必须有标题和预估时间

## 11. 错误处理

### 错误码定义
| 错误码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未认证/Token 过期 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如用户名已存在） |
| 500 | 服务器内部错误 |

### 常见错误场景
- 用户名已存在：409 Conflict
- 密码错误：400 Bad Request
- Token 过期：401 Unauthorized
- AI 生成失败：500 Internal Server Error

## 12. 数据安全

### 密码安全
- 使用 bcrypt 加密存储密码
- 密码哈希值加盐（bcrypt 自动加盐）
- 不在日志中记录密码

### Token 安全
- JWT Token 有效期：7天
- Refresh Token（可选，后续阶段）
- Token 存储在本地 Storage
- HTTPS 传输（生产环境）

### 数据权限
- 用户只能访问自己的数据
- API 层进行用户 ID 验证
- 数据库查询必须包含 user_id 过滤
